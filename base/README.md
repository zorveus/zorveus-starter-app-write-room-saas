# Base editor snapshot

Run `npm run dev:base` from the starter root. The shared editor and demo sessions work, while `base/config.ts` supplies an explicitly unconfigured billing state. The server receives no billing client and generation remains disabled. There is no automatic unmetered provider call.

The completed app is the default `npm run dev` entrypoint. See [the integration tutorial](../docs/tutorial.md) after your first completed customer flow.
